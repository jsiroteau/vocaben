Publishing (maintainer only)
Sends a vocabulary Excel file to the GitHub repository; every user's app then picks it up automatically. Only a GitHub token with write access to the repository can publish. The token is stored on this device only.
How to get a token On github.com (signed in): avatar → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Repository access: only the vocaben repository. Permissions: Contents → Read and write. Copy the token right away: GitHub shows it only once.
